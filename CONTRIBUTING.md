# Contributing to ASL-Project

Thank you for your interest in contributing to ASL-Project!

## Getting Started

1. Fork the repository
2. Clone your fork locally
3. Create a new branch
4. Make your changes
5. Commit and push your changes
6. Open a Pull Request

## Clone Repository

```bash
git clone https://github.com/your-username/ASL-Project.git
cd ASL-Project
